# Experiments

Screenshots and notes from experiments and visual checks, one folder per experiment (`YYYY-MM-DD-topic/`), each with a
README saying what was tried and what each image shows.

- [2026-11-04-charts-dumbbell](2026-11-04-charts-dumbbell/): the election dashboard's poll-vs-result dumbbell with a Tie line (before: grouped bars), the chart mark specs (solid grid, 24px bars, 10% wash, ringed dots, end labels), and chart colours following VS Code themes (Dracula, Tokyo Night, GitHub Light, Solarized Light, Nord's fallback), light and dark
- [2026-11-04-a11y-personas](2026-11-04-a11y-personas/): accessibility persona review (low vision at 20 px, small text at 12 px, colour vision simulation, keyboard, screen-reader tree, theme contrast sweep, reduced motion): the flow screenshots behind `docs/research/accessibility-personas.md`
- [2026-11-04-a11y-fixes](2026-11-04-a11y-fixes/): the persona review's fixes, re-measured: focus ring and failed badge at 12 px, focus coming back after dialogs and permission answers, the skip link, Settings and pane headers at 20 px, muted text in yaah light, Ayu Light and Dracula, named map markers, Lighthouse 95 → 100
- [2026-11-04-mdx-default](2026-11-04-mdx-default/): one MDX-first Markdown renderer for every text: the MDX docs reply and a plain Markdown reply (links, a code fence) look as before, light and dark
- [2026-11-03-mdx](2026-11-03-mdx/): an MDX docs section (Supabase style) in an agent reply, drawn as data with nothing run: frontmatter folded, imports hidden, `{expressions}` as code, Admonition, Tabs, Steps, details and an unknown component, light and dark
- [2026-11-03-permissions](2026-11-03-permissions/): answered permission requests folded into their tool cards as chips, reads in the chat's folders and trusted MCP servers answered without asking, and runs of tool calls grouped into one row (light and dark)
- [2026-11-03-chat-bubbles](2026-11-03-chat-bubbles/): the agent's reply in a soft muted bubble on the left (before/after at 2000, 1440 and a 420 px pane, light and dark, plus WKWebView), and why the user's bubble had sat mid-column
- [2026-11-03-terminals](2026-11-03-terminals/): terminal panes in the real app (⌘T beside a chat, the home screen's New terminal, a pane restored as a new shell after a restart, `top` full screen), an agent's command live in its tool card through ACP client terminals (the scripted agent), and throughput through xterm.js with WebGL (21 MB `cat` in 1.1 s)
- [2026-11-03-fullscreen-layout](2026-11-03-fullscreen-layout/): the chat column in full-screen windows (before/after at 1280–3440 px, sidebar shown and hidden, split panes), the agent asking to add a folder (`ui_request_folders`) for a diff of another repo, and expanding a rendered UI into a large dialog that stays in sync
- [2026-11-03-resume](2026-11-03-resume/): "Resume a session…" from ⌘K, a new pane's picker and the home screen's Quick chat menu. An agent's own sessions (started in its CLI) are listed per profile, searched and imported with their history, and "Already in yaah" opens the existing chat. Plus empty and can't-list states, and a read-only listing of a real Claude profile
- [2026-11-03-model-providers](2026-11-03-model-providers/): Settings → Model providers (OpenRouter with a keychain key, Bedrock on an AWS profile with the expired-SSO sign-in), binding agent profiles with the model picker, and readiness in the sidebar, light, dark and 420 px
- [2026-11-03-split-panes](2026-11-03-split-panes/): Ghostty-style split panes (picker, focus, per-pane chats, dividers, saved layout) and the sidebar that resizes and hides to a title bar, in the browser mock at 1440 and 1920 and in the real macOS app with its traffic lights
- [2026-11-03-chat-layout](2026-11-03-chat-layout/): the chat using the window's width (before/after at 800–2560 px), tool cards named from their input, command output and diffs in tool cards, and switching a chat's agent
- [2026-11-03-installer](2026-11-03-installer/): `install.sh` and the release pipeline tested for real: macOS arm64 and Linux arm64/x86_64 bundles built locally (Linux in the CI container, x86_64 emulated), served as a fake release; installs, reinstalls, uninstalls, tampered checksums, unsupported CPUs, timings
- [2026-11-03-ci-docker](2026-11-03-ci-docker/): CI tuned locally in an Ubuntu 24.04 container (mise tasks, timings, cold and warm), and the first tier A adapter conformance run: every npm preset, pinned and latest, with npm audit
- [2026-11-03-agent-guide-live-test](2026-11-03-agent-guide-live-test/): the same prompts after teaching agents about yaah's UI. Sonnet used it in 5 of 6 (2 of 6 before), Codex in 3 of 3
